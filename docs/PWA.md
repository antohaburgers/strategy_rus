# Мобильная оболочка и обновления

Постоянный адрес: https://antohaburgers.github.io/strategy_rus/

На iPhone открыть адрес в Safari → «Поделиться» → «На экран Домой». Приложение запускается с этой иконки. iOS может не применять manifest.orientation: в таком случае нужно физически повернуть телефон. На Android при доступности системного предложения в меню появляется «Установить игру».

`manifest.webmanifest` задаёт постоянные относительные id/start_url/scope, standalone, landscape и локальные PNG-иконки. Изображения используются только как системный значок; игровые персонажи и их портреты по-прежнему Canvas-only.

Service Worker ограничен папкой `/strategy_rus/`. При установке он полностью сохраняет оболочку. При загрузке сначала запрашивает актуальные файлы без браузерного HTTP-кэша, а при отсутствии сети возвращает сохранённые. Поэтому при следующем запуске с интернетом загружается актуальная опубликованная игра; переустанавливать иконку не нужно. Сохранённые открытые уровни остаются в прежнем ключе localStorage. Кэши других приложений не удаляются.

При возвращении приложения на экран проверяются Service Worker и `version.json`. Новая версия активируется автоматически в безопасный момент. Активный бой и подготовка с размещёнными юнитами не перезагружаются: обновление ждёт результата или сброса армии. Системное вытеснение приложения из памяти может сбросить текущий бой; между запусками сохраняется прогресс открытых уровней.

Для следующего выпуска обновлять одинаковую строку версии в `sw.js`, `version.json`, `<meta name="app-version">`. Новые обязательные файлы добавлять в CORE в `sw.js`. Все файлы текущего выпуска публиковать одним коммитом. Открытое приложение проверяет обновление при запуске, появлении сети и возвращении на экран.

Защита: user-select/touch-callout отключены, запрещены нативные zoom-жесты и двойной клик страницы, два быстрых касания одной позиции на поле не ставят и тут же убирают бойца. Перетаскивание и масштаб карты управляются прежними pointer-событиями. Настройки доступности ОС могут переопределять запрет масштаба.

Проверки: `node tests/pwa-sw.cjs`, `node tests/pwa-lifecycle.cjs`. Они проверяют состав офлайн-оболочки, свежую сетевую загрузку, офлайн-ответ, область регистрации, очистку только собственных кэшей, ожидание обновления при бое/размещённой армии и однократную перезагрузку. Установку на физический iPhone проверяет пользователь после публикации.
